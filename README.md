# MarkLeaf site

Landing page for [MarkLeaf – Markdown Viewer & Editor](https://chromewebstore.google.com/detail/markleaf/cnhfebgieoikabibmdeafajkccchadia), a Chrome extension that opens .md files as clean documents and lets you edit them in place.

- `index.html` — English
- `ko/index.html` — 한국어
- Static files only; deployed with Vercel on every push to `main`.
